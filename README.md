# 📖 oong의 비밀 일기장 (Secret Diary)

> 비밀번호 잠금 기능, 2인 공동 일기 작성, 커스텀 기념일 자동 계산 기능이 포함된 아기자기한 감성의 웹 다이어리 프로젝트입니다.

---

## 🌟 주요 기능 (Key Features)

- **🔒 진입 잠금 화면:** 사이트 접속 시 자물쇠 커버가 우선 표시되며, 비밀번호(`oong`) 입력 시에만 메인 달력 열람 가능
- **📅 월간 달력 기반 일기장:** 연/월 이동이 가능하며, 일기가 작성되거나 기념일이 있는 날짜에 스티커 뱃지 표시
- **👥 2인 다중 작성자 지원:** 작성자 선택 드롭다운(`옹심 🐾`, `휴 🌿`)을 제공하며, 같은 날짜에 각각 일기 중복 작성 가능
- **🎉 커스텀 기념일 자동 계산:**
  - 매년 반복 생일 (`2/9 옹심 생일`, `12/15 휴 생일`)
  - 휴 첫 방송일 (2025/06/21) 기준 **100일 단위 & 매년 N주년** 자동 표시
- **👑 관리자 전용 공간 (Admin System):**
  - 관리자 인증 시 비밀글 원본 열람 및 전용 관리 탭 생성
  - 일기 수정/삭제 권한 부여 (일반 방문자는 수정/삭제 불가)
- **🗑️ 휴지통 & 복구 시스템:** 삭제한 일기는 휴지통으로 이동하며, 관리자 공간에서 복구 및 영구 삭제 가능
- **💾 LocalStorage 데이터 보관:** 브라우저 저장소를 연동하여 새로고침이나 창을 닫아도 작성한 일기와 휴지통 데이터 유지

## 🛠️ 주요 트러블슈팅 및 개선 사항 (Troubleshooting)

### 1. 모바일 및 PC 화면별 표지 이미지 반응형 비율 유지 문제

- **문제 상황**:
- 화면 크기가 변함에 따라 표지 이미지(`cover.jpg`)가 과도하게 확대되거나 옆으로 찌그러지는 현상 발생.
- PC 화면 접속 시 다이어리 프레임이 전체 화면으로 늘어나 표지 하단(곰돌이 얼굴 영역)이 잘리는 스크롤 이슈 발생.
- **원인 분석**:
- 메인 컨테이너(`.diary-container`)의 가로 폭이 고정되지 않거나 퍼센트(`%`) 단위로만 설정되어 넓은 화면에서 끝없이 확장됨.
- **해결 방법**:
- `.diary-container`에 `width: min(380px, 85vw);` 및 `max-width` 제약을 부여하여 모바일에서는 화면에 맞게 꽉 차고, PC에서는 아담한 카드 형태로 중앙 정렬되도록 고정.
- `.lock-screen`에 `aspect-ratio: 3 / 4.3;` 속성을 적용하여 어떤 해상도에서도 표지의 원본 비율이 깨지지 않도록 설정.

---

### 2. 독립적인 애니메이션을 위한 발자국 요소를 표지 위에 정밀 배치

- **문제 상황**:
- 표지 배경 이미지와 곰발자국이 하나로 합쳐져 있어, 발자국 부분만 통통 튀는 애니메이션 효과 적용 불가.
- **해결 방법**:
- 발자국 이미지를 `paws.png` 투명 PNG 파일로 분리.
- CSS `position: absolute;`와 퍼센트 단위 위치 지정(`top`, `right`, `width`)을 활용하여 표지 배경 위의 원래 발자국 위치에 정밀하게 덮어씌움.
- `@keyframes bouncePaw` 애니메이션을 적용하여 발자국만 독립적으로 튀어 오르는 시각적 효과 구현.

---

### 3. HTML 시작 태그 누락으로 인한 레이아웃 붕괴 문제

- **문제 상황**:
- CSS 스타일을 수정했음에도 다이어리 카드 틀이 적용되지 않고 표지가 전체 화면으로 확대되는 현상 지속.
- **원인 분석**:
- `index.html` 내 최상위 감싸는 요소인 `<div class="diary-container">` 시작 태그가 누락되어 닫는 태그(`</div>`)만 존재하는 DOM 구조적 오류 발생.
- **해결 방법**:
- `index.html` 파일의 `<body>` 직후에 `<div class="diary-container">` 시작 태그를 정상적으로 복구하여 CSS 스타일이 정상 바인딩되도록 수정.

---

### 4. 브라우저 스타일 캐싱(Caching) 이슈

- **문제 상황**:
- `style.css` 파일을 수정 후 저장해도 브라우저에 이전 캐시가 남아있어 변경 사항이 즉시 반영되지 않음.
- **해결 방법**:
- `index.html`에서 stylesheet 로드 경로 뒤에 버저닝 파라미터(`<link rel="stylesheet" href="style.css?v=3">`)를 추가하여 브라우저가 최신 스타일시트를 강제로 불러오도록 처리.
